## Hi, it’s me.

Well, this is where I keep my technical tinkerings. I've spent a good chunk of my life in IT and full-stack development: Java on the backend, React on the front, Python for tools and automation, and plenty of other things along the way.

It doesn't all stay on a screen, either. I've messed around with Raspberry Pi projects, hardware automation, and getting software to make actual things do something. Some of that ends up useful. Some of it is just a rabbit hole I wanted to explore.

Lately, I've been bringing AI into the mix. And thank God, I'm finally getting around to things I've always wanted to try, like cinematography and video creation. I'm still very much an amateur at that part, but I'm enjoying making things and learning as I go.

So that's what this page is about: software I've built, things I've wired together, and whatever I'm experimenting with now. A lot of the newer stuff lives under **L3V**. The tools, cinema toolkit and videos are linked below if you want to have a look.

### Things you can poke around in

- **[My tools — tools.l3v.ai](https://tools.l3v.ai)** — the place to try the AI and creative tools I'm working on.
- **[AI Cinema Toolkit](https://toolkit.l3v.ai/)** — dig into lighting, lenses, camera movement, focus and what makes a shot work. I like understanding the knobs, not just turning them.
- **[AI video model guide](https://github.com/despanitech/AI-l3v-tools-UI)** — model strengths, limitations and practical workflows. Useful when you're trying to work out which tool fits the job.
- **[L3V](https://l3v.ai)** — the visual side of the experiments: worlds, characters and film ideas.
- **[Echora](https://www.youtube.com/@echoramedia)** — where the films end up. Have a look at what came out of all that testing.

I also build software and practical AI tools through **[Despani Technologies](https://despanitech.com)**. Full-stack applications, integrations and automation are still very much my day-to-day world.

### A few older rabbit holes

There's some history here too: **[YUIJavaLoader](https://github.com/levancho/YUIJavaLoader)**, a Java port of the YUI PHP Loader, and **[MVCN Framework](https://github.com/levancho/MVCN-Framework)** for Adobe Flex/AIR. Different tools, same curiosity.

Try something, tell me what breaks, or show me a better way to do it. That's the fun part.
